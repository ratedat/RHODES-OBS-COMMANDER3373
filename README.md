# RHODES OBS COMMANDER3373

**統合戦略の「いま」を、見やすく、あなたらしく。**

**秘宝・オペレーター・特殊値を、自由なレイアウトでOBSへ。**

アークナイツ「統合戦略」のラン情報を管理し、OBSへ表示するWindows用ツールです。<br>
**レスポンシブ表示・自由配置・CSSカスタマイズ。** ドラッグや数値指定で配置を詰め、配信枠に合わせた画面を作れます。<br>
手動入力、画面認識による入力補助、スタッフの遠隔入力で、個人のローグ配信から大会中継まで支えます。

## できること

「今、どんな秘宝を持っている？」「どのオペレーターを招集した？」「特殊値はいくつ？」<br>
ゲーム画面だけでは追い切れないランの情報を、視聴者や実況・解説者が確認できる形で配信に添えられます。

### 配置は自由に、仕上げは細かく

**秘宝は画面下部へ、オペレーターはサイドへ、特殊値は見やすい場所へ。** ゲーム画面や立ち絵、コメント欄を避けながら、必要な情報を組み合わせられます。

- **見ながら動かす。** 「実出力で編集」で、OBSと同じ表示を確認しながら部品をドラッグ・リサイズ。
- **数値でそろえる。** X・Y座標、幅・高さを指定して微調整。部品の表示・非表示や前後関係も設定できます。
- **まとめても、分けても。** ひとつのカスタムOverlayで画面全体を構成するほか、秘宝・オペレーターなどを個別のブラウザソースとしてOBSへ追加できます。
- **透過で重ねる。** 背景を透明にしてゲーム映像へ重ねたり、背景・枠を付けて配信の空きスペースに配置したりできます。

カスタム配置は1920×1080を基準に編集します。OBSに置いたときの余白や他の画面要素との位置関係まで、プレビューを見ながら詰められます。

### 表示枠に合わせて整う、レスポンシブ表示

**横長の秘宝欄にも、縦長のオペレーター欄にも。** 秘宝・オペレーターの一覧は、表示枠の幅に応じて列数や折り返しが変わります。枠に収まらない一覧は、自動スクロールで順に見せられます。

- 横型・縦型・コンパクトなどのレイアウトと、自由配置のカスタムOverlayを用意。
- 名前や情報を添える表示と、アイコンを中心にした省スペースな表示を選択。
- 表示枠の大きさやスクロール速度を調整して、ゲーム画面とのバランスを取れます。

### CSSで、配信の雰囲気までそろえる

**文字色を変えるだけでなく、背景・枠・余白まで自分の配信に合わせて。** フォント、文字サイズ、配色、背景の透明度、枠線、角丸、影などをユーザーCSSで細かくカスタマイズできます。

基本的な色や文字サイズはアプリの簡易設定から変更でき、さらに作り込みたいときはライブCSSで出力を確認しながら編集できます。統合Overlayと個別ウィンドウのCSSは分けて設定可能です。

配置はライブレイアウト、装飾はCSS。同梱のCSSガイドには見本と編集用プレビューがあり、配信デザインを作るための土台として使えます。詳しくは[CSSカスタマイズガイド](docs/guides/output-css-customization.md)をご覧ください。

### ランの情報を、ひとつにまとめる

**秘宝、招集オペレーター、分隊、等級、ボス、テーマごとの特殊値をまとめて管理。** 日本版のIS#2〜IS#6に対応し、レア度別のオペレーター表示や、各テーマ固有の情報も配信へ出せます。

見せたい情報だけを選べるので、秘宝一覧を中心にしたローグ配信から、オペレーターに注目する大会配信まで、目的に合わせて構成できます。

### 手動入力でも、画面認識でも

**ゲームへ接続せず、検索・選択・数値入力だけで使い始められます。** 手動入力を基本に、必要に応じてADB・MAAFrameworkによる画面認識を入力補助として利用できます。認識後の訂正や追加も、同じ操作画面から行えます。

| 使い方 | こんな運用に |
| --- | --- |
| 手動入力 | 見せたい情報だけを自分で選ぶ。実況・解説担当が画面を見ながら更新する。 |
| 画面認識による入力補助 | ADB接続したゲーム画面から情報を取得し、内容を確認・修正して使う。 |
| 大会スタッフの遠隔入力 | 別の担当者がブラウザーから情報を送り、配信PCの表示を更新する。 |

### 大会の「プレイする人」と「入力する人」を分ける

**選手のランを見ながら、スタッフが配信表示を更新。** 遠隔入力用の画面をブラウザーで開き、オペレーター・秘宝・特殊値などの変更をまとめて送信できます。得点やメモを表示する大会用パーツも用意しています。

小規模な運用では、アプリから入力担当者用のURLを発行する「簡易公開」を利用できます。大会ルールに合わせて必要な情報だけを出す使い方や、独自の配信枠と組み合わせる使い方にも対応します。[大会遠隔入力の使い方](docs/guides/tournament-remote-input.md)をご覧ください。

## 入手と導入

現在は開発・テスト段階です。**GitHub Releasesでの実行ファイル配布は準備中です。** 公開状況は[Releases](https://github.com/ratedat/RHODES-OBS-COMMANDER3373/releases)で案内します。

配布ZIPをお持ちの場合は、次の手順で始められます。

1. ZIPを新しいフォルダーへ**すべて展開**し、`RhodesSuki.exe` を起動します。
2. 上部で統合戦略テーマを選び、「ラン」「特殊値」「選択」で表示したい情報を入力します。
3. 「出力」で配信サーバーを起動し、**カスタムOverlay**のURLをOBSのブラウザソースへ追加します。幅1920・高さ1080が基準です。

詳しい操作、更新方法、困ったときの確認先は[はじめ方とOBS設定](docs/guides/startup-guide.md)にまとめています。

> GitHubの「Code → Download ZIP」はソースコードです。そのまま起動できる配布版ではありません。ソースから動かす場合は[開発環境の準備](docs/development-setup.md)を参照してください。

## 動作環境

| 用途 | 必要なもの |
| --- | --- |
| アプリの操作 | Windows x64、書き込み可能な展開先 |
| 配信画面への表示 | OBS Studioのブラウザソース、Node.js（アプリから導入可能） |
| 画面認識による入力補助 | ADB接続できるAndroid端末・エミュレーター。認識の基準は1280×720・16:9 |
| 大会の遠隔入力 | 配信PCと入力端末のインターネット接続、入力担当者用のブラウザー |

配布版にはアプリの.NET実行環境を含みます。軽量版は、配信サーバーや大会入力に必要な追加ランタイムを初回利用時に取得します。通常の手動入力にADB接続は不要です。

## 現在の制限

- 認識結果には誤りや取りこぼしがあり得ます。取得後に表示内容を確認し、必要に応じて手動で訂正してください。
- **歳の銭OCR（有効銭・保有銭）は停止中です。** 銭は手動入力してください。
- 所持一覧から消えた秘宝の自動削除と、ゲーム内だけで始めた新しいランの確実な自動判定は未対応です。新しいランではアプリ側の「ランをクリア」も使用してください。
- 大会入力の簡易公開URLは、停止またはアプリ終了後に失効します。継続運用する大会では、事前に接続と表示を確認してください。
