# RHODES OBS COMMANDER3373 公開デバッグ版

統合戦略の状態をADBとMAA-OCRで取得し、OBSへ表示するテスト版です。

## 起動

1. 配布ZIPをすべて展開します。ZIP内から直接起動しないでください。
2. 展開先の `RhodesSuki.exe` を実行します。
3. 上部の一覧から、使用する統合戦略テーマを選びます。
4. 手動入力だけで使用する場合は、「ラン」「特殊値」「選択」から入力してOBS表示へ進めます。

## ADB接続と取得

1. エミュレーターを起動し、ゲームを1280x720の16:9横画面にします。
2. 左の「接続設定」で「自動検出」を押します。
3. 候補が複数ある場合は、使用中のエミュレーターとserialを選びます。
4. 「接続・撮影」を押し、ゲーム画面が取得できることを確認します。
5. ゲームを探索中のマップ画面に戻し、「ラン」の取得ボタン、または上部の「画面を取得して反映」を実行します。
6. オペレーターと秘宝は「選択」で対象一覧を開き、「表示中を取得」から取得します。処理中はゲームを操作しないでください。

公開デバッグ版ではIS#2からIS#6の専用認識を利用できます。歳の銭OCR（有効銭・保有銭）は安定化まで停止しているため、「特殊値」の銭欄から手動入力してください。その他の誤認識や取りこぼしも「ラン」「特殊値」「選択」から手動修正できます。

## OBS表示

1. 「出力」で「Node.js導入」を押します。インストーラーと管理者権限は不要です。
2. 配信サーバーを起動します。
3. カスタムOverlay URLをコピーし、OBSの「ソース」「ブラウザ」のURLへ貼り付けます。
4. 統合Overlayは幅1920、高さ1080が基準です。個別部品は表示されたURLと推奨サイズを使います。

ADBと手動入力だけならNode.jsは不要です。

## 不具合報告

「デバッグ・報告」→「バグ報告ZIP」の「作成」から、調査用のZIPを作成できます。ログ・認識画像・設定が含まれるため、共有前に内容を確認してください。報告の手順は[不具合報告と機能要望](https://github.com/ratedat/RHODES-OBS-COMMANDER3373/blob/main/docs/guides/feedback.md)を参照してください。

本文には「使用エミュレーター」「実行した取得項目」「期待した結果」「実際の結果」を書いてください。報告ZIPは実行フォルダ内の `RHODES OBS COMMANDER3373 Debug Logs/Bug Reports` に生成されます。

タップとスワイプは指定範囲内でランダム化されています。
