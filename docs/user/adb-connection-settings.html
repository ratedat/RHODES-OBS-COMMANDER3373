ADB接続設定ガイド

RHODES OBS COMMANDER3373で、エミュレーターを安全に接続し、MAAFrameworkの撮影・入力方式を選ぶための説明です。

最初に知っておくこと

「選択内容で上書き」を押すと、選んだプロファイルのADB実行ファイル、serial、推奨撮影方式、推奨入力方式で画面上の値を上書きします。プロファイルを選ぶだけでは上書きしません。
  1. プロファイルを選び、内容を確認してから「選択内容で上書き」を押します。
  2. 必要ならADBパスとserialを修正し、「接続・撮影」で確認します。
  3. 次回も使う設定だけ、最後に「保存」を押します。適用と保存は別操作です。

MAAの撮影・入力方式

撮影と入力は独立しています。高速撮影が使えても、高速入力が使えるとは限りません。強化機能が利用できない場合は、指定したフォールバック方式へ戻ります。

対象高速撮影（EmulatorExtras）高速入力（EmulatorExtras）推奨運用
MuMu Player 12対応。external_renderer_ipc.dllを確認します。対応。MuMu 6.3.2.0以上を確認します。撮影とタッチを個別にON/OFFし、それぞれフォールバックを指定します。
LDPlayer 9対応。ldconsole.exeとldopengl64.dllを確認します。MAA公式のEmulatorExtras入力対象外です。高速撮影だけをONにし、入力はMAA Touch、MiniTouch、ADB入力から選びます。
その他プロファイルとMAA検出結果に従います。プロファイルとMAA検出結果に従います。標準方式から接続確認し、必要な場合だけ互換方式へ変更します。
LDPlayerでは高速撮影を有効にしても入力方式を書き換えません。接続時のLDPlayer process IDはMaaToolkitの端末検出結果から取得し、既存のextras.ld.pidを保持します。

接続強化の各設定

MuMu高速スクリーンショット

MuMu IPCによる低遅延・ロスレス撮影を優先します。IPC DLLが見つからない場合は「高速撮影失敗時」の方式へ戻ります。

MuMu高速タッチ

MuMu IPCでタップとスワイプを送ります。Manager versionまたはIPC要件を満たさない場合は「高速タッチ失敗時」の方式へ戻ります。

MuMuネットワークブリッジ

複数instanceやバックグラウンド常駐時に接続先を明示します。OFFではserialからinstance番号を推定します。

LDPlayer高速スクリーンショット

LDPlayerの描画ライブラリによるロスレス撮影を優先します。高速入力は有効にせず、画面上で選択したMAA入力方式を維持します。

安全とトラブルシュート

  • 「能力を再確認」はローカルファイルだけを調べ、ADB接続、撮影、タップを行いません。
  • ADB server再起動、ADB process再起動、エミュレーター再起動は別の回復設定です。必要な項目だけ明示的に有効化してください。
  • LDPlayer高速撮影が不可の場合は、ルートがLDPlayer 9本体のフォルダーか、ldconsole.exeとldopengl64.dllが存在するか確認します。
  • 接続できるのに撮影できない場合は、撮影方式をRaw/GZip優先へ変更して切り分けます。
