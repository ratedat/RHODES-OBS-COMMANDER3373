OBS Browser Source customization

出力CSSカスタマイズガイド

統合Overlayと個別ウィンドウの文字色、背景色、枠色、文字倍率を調整し、外部フォントや外部画像も配信画面へ適用できます。このHTMLは単体で開けます。

  1. 3373の「出力」を開く
  2. 統合Overlayまたは個別ウィンドウの設定を選ぶ
  3. 上級者向けユーザーCSSへ貼り付ける
  4. 「保存して反映」を押し、OBSを再読み込みする

設定場所と適用範囲

CSSは操作アプリ本体ではなく、配信画面として使うOverlayだけへ適用されます。

統合Overlay

/overlay

compact、縦型、横型、full、ライブレイアウトへ共通して適用します。

個別ウィンドウ

/overlay/part/*

ラン状態、秘宝、オペレーター、効果、ボス、特殊値へ共通して適用します。

保存方法

保存して反映

入力しただけでは保存されません。対象欄の保存ボタンを必ず押してください。

安定したCSS変数とセレクター

細かいHTML階層より、次の変数とルートクラスを優先してください。

--overlay-font-color

基本文字色。

--overlay-background-rgb

枠背景色。カンマなしのRGB値を指定します。

--overlay-background-alpha

枠背景の不透明度。0から1。

--overlay-canvas-background-rgb

Browser Source全体の背景色。

--overlay-canvas-background-alpha

全体背景の不透明度。0から1。

--overlay-border-color

カードと部品の枠色。

--overlay-accent-color

見出しや重要値の強調色。

--overlay-font-scale

Overlay全体の文字倍率。

--overlay-item-background-rgb

秘宝・オペレーター・数値など、内側カードの背景色。

--overlay-item-background-alpha

内側カード背景の不透明度。0から1。

--overlay-item-border-color

内側カード専用の枠色。

--overlay-strong-font-color

名前や数値など、強い文字の色。

--overlay-muted-font-color

ラベルや補足など、弱い文字の色。

--overlay-shadow

統合枠・個別枠の影。消す場合はnone。

.overlay-app

すべての統合Overlay。

.overlay-part-operators

オペレーター個別ウィンドウのみ。

.overlay-part-special

特殊値個別ウィンドウのみ。

透明キャンバス＋半透明枠

ゲーム画面へ情報カードだけを重ねる基本例です。画面上では「全体背景」をOFF、「枠背景」をONにして同じ構成を作れます。

:root {
  --overlay-canvas-background-rgb: 0 0 0;
  --overlay-canvas-background-alpha: 0;
  --overlay-background-rgb: 8 11 12;
  --overlay-background-alpha: .86;
}

白背景＋シアン枠＋赤アクセント

上の「白＋シアン枠」プリセットと同じ構成です。内側カードも変数だけで揃うため、各divへの高詳細度セレクターは不要です。

@import url("https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;700&display=swap");

:root {
  --overlay-font-color: #0a0a0a;
  --overlay-canvas-background-rgb: 255 255 255;
  --overlay-canvas-background-alpha: 1;
  --overlay-background-rgb: 255 255 255;
  --overlay-background-alpha: 1;
  --overlay-border-color: #00ffff;
  --overlay-accent-color: #c8001e;
  --overlay-item-background-rgb: 255 255 255;
  --overlay-item-background-alpha: 1;
  --overlay-item-border-color: #00ffff;
  --overlay-strong-font-color: #111111;
  --overlay-muted-font-color: #333333;
  --overlay-shadow: none;
}

.overlay-app,
.overlay-part {
  font-family: "Noto Sans JP", sans-serif;
}
不透明度は0から1です。完全不透明は1で、1.8や1.80ではありません。エディターは範囲外の値を検出して警告します。
CSS側で追加した画像や影まで消したい場合は、全体背景・枠背景それぞれのOFF用クラスで明示的に解除します。
html.overlay-canvas-background-disabled .overlay-app,
html.overlay-frame-background-disabled .overlay-part-shell {
  background: transparent !important;
  background-image: none !important;
  box-shadow: none !important;
}

外部フォント・外部画像・外部CSS

Overlayは配信画面なので、HTTPS上のフォントや画像を読み込めます。操作アプリ本体のUIには影響しません。

Google Fonts

@import url("https://fonts.googleapis.com/css2?family=Noto+Sans+JP:wght@400;700&display=swap");

.overlay-app,
.overlay-part {
  font-family: "Noto Sans JP", sans-serif;
}

Webフォントを直接指定

@font-face {
  font-family: "Tournament Sans";
  src: url("https://example.com/font.woff2") format("woff2");
  font-display: swap;
}

.overlay-app { font-family: "Tournament Sans", sans-serif; }

外部背景画像

.overlay-app {
  background-image: url("https://example.com/overlay.png");
  background-position: center;
  background-repeat: no-repeat;
  background-size: cover;
}

個別パーツだけ装飾

.overlay-part-special .special-overlay-chip {
  border-color: #d9ad47;
  color: #fff4cf;
  background: rgb(22 16 5 / 88%);
}
外部サーバー停止、URL変更、通信障害、CORS制限が起きると表示が欠けます。大会では管理下の安定したHTTPS配信先を使い、OBS Browser Sourceで事前確認してください。javascript:を含むCSSと65,536文字を超えるCSSは拒否されます。

出力プロファイルの保存

出力画面のJSONエクスポートには、CSS、簡易色設定、背景、スクロール、部品配置、個別ウィンドウ設定がまとめて保存されます。インポート前にプレビューし、統合Overlayと個別ウィンドウの両方を確認してください。

  • OBSのURLとポートが現在の3373と一致している
  • 統合Overlay用CSSと個別ウィンドウ用CSSを取り違えていない
  • 全体背景と枠背景それぞれのON/OFF・不透明度を確認した
  • 外部フォント読み込み後に文字が見切れていない
  • 外部画像がOBSを動かすPCから開ける
  • 縦型、横型、full、個別パーツを必要な範囲で確認した
